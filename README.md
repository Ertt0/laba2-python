# StreamStats - потоковый анализатор событий

## Описание

streamstats - Python-пакет для анализатора событий из файлов CSV и JSONL

## Возможности
- Чтение файлов CSV с заголовком и JSONL.
- Проверка обязетльных полей событий.
- Подсчет общего числа событий.
- Подсчет количества событий каждого уровня.
- Подсчет количества событий каждого источника.
- Вывод top-5 источников ошибок уровня ERROR/CRITICAL.
- Поиск первой и последней временной метки.
- Формирование JSON-отчёта.
- Объединение статистики нескольких файлов.

## Требования
- Python 3.12 или новее.
- uv для установки зависимостей и запуска команд.

## Установка
Установите зависимости:
```uv sync```

## CSV

CSV-файл должен содержать заголовок с названиями полей:

```timestamp,level,source,message
2021-03-20T20:00:00Z,INFO,web,Hello
2023-03-20T10:20:01Z,ERROR,auth,Hi```

## JSONL

В JSONL каждый объект события записывается на отдельной строке:

```{"timestamp":"2022-10-21T12:00:00Z","level":"INFO","source":"web","message":"started"}
{"timestamp":"2025-10-21T12:00:01Z","level":"ERROR","source":"db","message":"failed"}```

## Использование

### Анализ одного файла

Для CSV:

```bash
uv run python -m streamstats analyze events.csv --format csv --output report.json
```

Для JSONL:

```bash
uv run python -m streamstats analyze events.jsonl --format jsonl --output report.json
```

### Анализ нескольких файлов

Можно передать несколько файлов одного формата:

```bash
uv run python -m streamstats analyze events1.jsonl events2.jsonl --format jsonl --output report.json
```

Статистика рассчитывается по всем переданным файлам.

### Пропуск некорректных записей

Чтобы пропускать ошибочные строки и продолжать обработку, используйте параметр `--skip-invalid`:

```bash
uv run python -m streamstats analyze events.jsonl --format jsonl --output report.json --skip-invalid
```

Без этого параметра обработка останавливается при первой ошибочной записи. Программа сообщает об ошибке с указанием файла и номера строки и завершается с кодом `2`.

В режиме `--skip-invalid` ошибочные записи пропускаются, предупреждения записываются в лог, а количество пропущенных записей включается в отчёт.

### Справка

```bash
uv run python -m streamstats --help
uv run python -m streamstats analyze --help
```

## Результат

Программа сохраняет статистический отчёт в JSON-файл. Он содержит общее количество событий, распределение по уровням логирования и источникам, наиболее частые источники ошибок, временные границы анализа и количество пропущенных записей.

Назначение основных модулей:

- `models.py` — модель события и уровни логирования.

- `analysis.py` — расчёт статистики.
- `report.py` — подготовка JSON-отчёта.
- `errors.py` — классы исключений.
- `__main__.py` — интерфейс командной строки и обработка ошибок.

## Обработка ошибок

В проекте предусмотрены базовое исключение `StreamStatsError` и специализированные ошибки для неподдерживаемого формата, некорректного события, неверной временной метки и ошибок конфигурации CLI.

## Принцип работы

Обработка организована как последовательный конвейер.

Записи читаются последовательно, что позволяет обрабатывать файлы без загрузки всего содержимого в память.
